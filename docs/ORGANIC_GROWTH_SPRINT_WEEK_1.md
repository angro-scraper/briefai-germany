# BriefAI Germany — seven-day organic sprint

This is an execution board for the first seven days of the 30-day growth goal.
It is deliberately based on useful content and transparent distribution, not
bulk posting, purchased traffic, fake testimonials or review requests.

## Starting point and success signal

- Authoritative starting point: 14 Firebase Authentication accounts, 40
  completed analyses and zero verified paid subscriptions; see
  `ORGANIC_GROWTH_BASELINE.md`.
- The first week does **not** claim a result in advance. Its job is to create
  attributable distribution and identify which topic/language produces real
  account creation and first analyses.
- Use Firebase Authentication and server-verified purchases for results. Store
  impressions or installs are supporting acquisition signals only.

## Channel qualification checklist

Before proposing any external post, comment, direct message or listing:

1. Read the current destination rules and check whether a commercial/resource
   mention with links is allowed.
2. Match the message to a real, current question or to a directory category;
   never add generic link drops.
3. Identify AMIA Technologies and BriefAI clearly.
4. State that BriefAI is an information tool and not legal, tax, social,
   immigration or medical advice whenever the context makes this relevant.
5. Include only reviewed language claims and both store links when the
   destination allows store links.
6. Ask the user for immediate confirmation of the exact copy and destination
   before the external action.

## Week-one decision gates

- If a topic earns guide visits but no store clicks, improve its call to action
  before creating more content on it.
- If store clicks rise but first analyses do not, investigate the first-use
  experience instead of increasing promotion volume.
- If registrations rise but verified purchases do not, check value delivery,
  entitlement display and purchase reliability before increasing reach.
- Stop any channel that rejects the transparent resource format or whose rules
  prohibit the post; do not try to evade moderation.
